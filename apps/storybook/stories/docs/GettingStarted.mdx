# Getting started

The guides are on the haus docs site, which is the one place haus is explained:
**What haus is** (the four layers, and what has already been decided), **Install** (point shadcn at
the registry, import the tokens, add a component), **Composition** (the vocabulary that makes a
screen read as one system) and **The quality bar** (what every published component has been held
to).

This Storybook is the workshop: every component in every documented state, with its controls, its
accessibility checks, and the screenshots the tests compare.
