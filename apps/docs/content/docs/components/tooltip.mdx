## Placement and timing

`placement` is `top` by default, or `bottom` for a control near the top of the screen. `delay`
waits before showing on hover; it never delays focus.

<Notice tone="warning">
A tooltip is never the only place information lives: touch has no hover. And it holds a short
string only. If it needs a link, a control or more than a line, use Popover.
</Notice>

## Accessibility

- Shows on keyboard focus as well as on hover. The child must be focusable.
- The child is described by the tooltip's text, which is added to its `aria-describedby`.
- Escape hides it without moving focus. The pointer can move onto it, and it stays until the pointer
  or focus leaves, with no timeout.
