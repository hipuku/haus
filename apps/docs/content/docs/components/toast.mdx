## Usage

```tsx
import { Toast } from '@/components/haus/components/Toast'

<Toast
  tone="success"
  title="Palette saved"
  description="3 colours added to Brand."
  onClose={() => dismiss(id)}
/>
```

## What you provide

Toast is the notice itself. Positioning, a queue, stacking and an auto-dismiss timer are yours:
render toasts into your own container and remove them when you are done. `onClose` adds a dismiss
button; `action` adds a control on the title's row.

To play its exit, set `data-state="closed"` on the toast, then remove it once the animation ends.

## Tones and appearances

`neutral`, `info`, `success`, `warning` and `error`, each `subtle` (the default) or `solid`.

## Accessibility

- Announced when it appears: politely, or at once for an `error`, with the title and description
  read as one notice.
- Not focusable itself. The action and the dismiss button keep their own place in the tab order.

<Notice tone="warning">
A toast that appears already holding its text is not reliably announced. Keep your container on the
page and render toasts into it. For a notice that must not be missed, keep a record the user can
open again: an announcement is not a record.
</Notice>
