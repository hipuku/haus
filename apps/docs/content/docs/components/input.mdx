## Usage

```tsx
import { Input } from '@/components/haus/components/Input'

<Input label="Email" type="email" hint="We never share it." value={email} onChange={e => setEmail(e.target.value)} />
```

## States

`hint` is a line of help under the field. `error` marks it invalid and shows above the hint, which
stays, because it is what the user needs to fix the field. `prefix` and `suffix` hold a unit or a
symbol inside the field. An Input stands level with a default Button beside it.

<Notice tone="info">
`required` marks the field and sets `aria-required`, not the browser's own `required`, so the
browser shows no validation bubble of its own. Show the problem with `error`.
</Notice>

## Accessibility

- A native input with a real `label`: clicking the label focuses the field.
- The hint and error are read as the field's description. An error is announced when it appears.
- `error` sets `aria-invalid`, and is not shown by colour alone.
