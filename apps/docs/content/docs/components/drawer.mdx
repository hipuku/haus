## Usage

```tsx
import { Drawer } from '@/components/haus/components/Drawer'

<Drawer open={open} onClose={() => setOpen(false)} title="Filters">
  {filters}
</Drawer>
```

## API

Drawer also takes its element's own attributes and forwards its ref. `className` lands on the
backdrop and `dialogClassName` on the panel.

## Side

`side` is `end` by default, which is the right edge on a left-to-right page and flips for
right-to-left. `size` sets the panel's width.

<Notice tone="info">
A Drawer is a Modal anchored to an edge. For a dialog in the middle of the page, use Modal.
</Notice>

## Accessibility

- Needs a name: `title`, or `aria-label` when there is no visible title.
- Focus moves in on open and returns on close. Tab stays in the panel, and Escape closes it.
- The page behind does not scroll while it is open.
