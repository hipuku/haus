## Variants and tones

`primary`, `secondary` and `ghost`, with `secondary` the default and `ghost` the one for toolbars.
Every tone works at every variant, as on Button.

## Sizes

| `size` | Height | Use it for |
| ------ | ------ | ---------- |
| `sm` | 24px | Dense rows. The smallest size that meets the WCAG minimum target |
| `md` | 28px | The default |
| `lg` | 36px | Beside a default Button, so the two stand level |

<Notice tone="warning">
IconButton's sizes are one step smaller than Button's of the same name. Next to a `md` Button, use
a `lg` IconButton.
</Notice>

## Loading

`loading` swaps the icon for a spinner. It keeps its focus and does not run `onClick` while it
loads. It is `type="button"` unless you set `type="submit"`.

## Accessibility

- `label` is required: an icon has no accessible name of its own, so `label` is what is announced.
- The icon is hidden from screen readers, so it never adds a second name.
- For a link, pass the anchor as the single child with `asChild`. The label still applies.
