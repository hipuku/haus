## Usage

```tsx
import { ConfirmDialog } from '@/components/haus/components/ConfirmDialog'

<ConfirmDialog
  open={open}
  title="Delete workspace?"
  description="Its records and history are deleted with it."
  confirmLabel="Delete workspace"
  tone="error"
  pending={deleting}
  onConfirm={deleteWorkspace}
  onCancel={() => setOpen(false)}
/>
```

## Kinds and tone

- `kind="confirm"` asks, with Cancel and the confirm button. The default.
- `kind="alert"` reports, with one button and nothing to cancel.
- `tone="error"` colours the confirm button for an action that destroys something.

Write `confirmLabel` as the action, "Delete workspace" rather than "OK": it is the last thing a
reader hears before acting.

## While it runs

Set `pending` while the action runs. The confirm button shows it is working, and Cancel, Escape
and the close button do nothing, so the action is not abandoned half way.

<Notice tone="info">
A click on the backdrop never dismisses a ConfirmDialog, and that cannot be turned on: the point
is a deliberate answer.
</Notice>

## Accessibility

- Announced as an alert dialog, with its description read alongside the title.
- Focus starts on Cancel, so Enter does the safe thing. An `alert` starts on its only button.
- Escape and the close button cancel. Tab stays in the dialog, and focus returns on close.
