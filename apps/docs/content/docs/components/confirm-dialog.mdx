vault and core each built one. Focus starts on Cancel, so Enter does the safe thing; the confirm button carries the tone of the action; while the action runs the button shows it and the dialog cannot be dismissed; a backdrop click never dismisses it. It is an `alertdialog`, so it is announced as interrupting, with its description.
