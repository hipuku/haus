## Sizes

`xs`, `sm`, `md`, `lg` and `xl`. `md` is the default. `xs` and `xl` go beyond the shared scale
because an avatar is a picture, not a control: a very small one is useful in a dense table.

## Colour

The colour comes from `name`, so the same person is the same colour everywhere with nothing to
store. With no `name`, a person glyph is shown instead of initials.

<Notice tone="info">
The colour is not an identity: there are five, so names often share one. The initials and the
accessible name are what tell people apart.
</Notice>

## Accessibility

- Announced as one image, labelled with `name`, or with `alt` if you pass one.
- `status` is added to that label as a word, so the dot is never colour alone.
- Not interactive. Wrap it in a link or button if it should do something.
