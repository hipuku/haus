## Usage

```tsx
import { RadioGroup } from '@/components/haus/components/Radio'

<RadioGroup
  label="Plan"
  name="plan"
  value={plan}
  onChange={setPlan}
  options={[
    { label: 'Free', value: 'free' },
    { label: 'Team', value: 'team', hint: 'Up to 20 people' },
  ]}
/>
```

## Options

Options come from `options`, not from children. Each has a `label`, a `value`, and an optional
`hint` and `disabled`. `orientation="horizontal"` lays them in a row. `onChange` gives you
`(value, event)`, and it is uncontrolled unless you pass `value`.

## Accessibility

- One tab stop for the whole group. The arrow keys move the selection.
- Announced as a group named by `label`, so the question is read before the options.
- `required` and `error` set `aria-required` and `aria-invalid` on the group, and an error is
  announced when it appears.
