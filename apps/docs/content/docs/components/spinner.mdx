## Sizes

`text` matches the text it sits beside, for a spinner inside a label or a button. `sm` and `md` are
for a spinner that stands on its own, such as a loading panel.

## Announcing the wait

By default a Spinner is a status region labelled with `label`, so a screen reader can tell that
something is happening. If something else already announces the wait, pass that text as
`announcedBy` and the spinner stays silent, so the wait is not announced twice.

<Notice tone="warning">
An announcement is not guaranteed, because a region that appears already holding its text is not
reliably read. For a wait that must be heard, keep a live region on the page and put the text in it
when loading starts, then pass that text as `announcedBy`.
</Notice>

## Accessibility

- Not interactive.
- With reduced motion it keeps turning, slower, because a still ring reads as broken.
