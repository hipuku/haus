A list of actions opened from a trigger. Three products drew their own (vault, core and maple). It is a `Popover` with `role="menu"`, so placement, dismissal and motion are Popover's; it adds the menu pattern: focus moves to the first item on open, the arrows move between items and skip disabled ones, and choosing an item closes the menu and returns focus to the trigger.
