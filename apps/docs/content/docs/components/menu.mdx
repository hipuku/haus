## Usage

```tsx
import { Menu, MenuItem, MenuSeparator } from '@/components/haus/components/Menu'

const trigger = useRef<HTMLButtonElement>(null)

<div style={{ position: 'relative' }}>
  <Button ref={trigger} aria-haspopup="menu" aria-expanded={open} onClick={() => setOpen(o => !o)}>
    Actions
  </Button>
  <Menu open={open} onClose={() => setOpen(false)} triggerRef={trigger} aria-label="Actions">
    <MenuItem onSelect={rename}>Rename</MenuItem>
    <MenuSeparator />
    <MenuItem tone="error" onSelect={remove}>Delete</MenuItem>
  </Menu>
</div>
```

## API

Menu also takes its element's own attributes and forwards its ref. It is a Popover, so placement,
alignment and width work as they do there.

## Parts

- `MenuItem`: one action, with an optional `icon` and `shortcut`. `tone="error"` for an action that
  destroys something. Choosing it runs `onSelect` and closes the menu.
- `MenuSeparator`: a rule between groups.
- `MenuLabel`: a heading over a group. Not an action and not focusable.

<Notice tone="info">
`shortcut` only displays a key. It does not bind one: wire the shortcut yourself.
</Notice>

## Accessibility

- `aria-label` is required, so the menu is announced with a name.
- Focus moves to the first item on open. The arrow keys move between items and skip disabled ones,
  Home and End jump to the ends, and Enter or Space chooses.
- Escape or a click outside closes it, and focus returns to the trigger.
