## Usage

```tsx
import { Select } from '@/components/haus/components/Select'

<Select
  label="Role"
  value={role}
  onChange={setRole}
  options={[
    { label: 'Author', value: 'author', hint: 'Can propose and revise' },
    { label: 'Viewer', value: 'viewer' },
  ]}
/>
```

## Options and forms

Options come from `options`. Each has a `label`, a `value`, and an optional `hint` shown under the
label, which a native `<select>` cannot do, and `disabled`. Select is controlled: pass `value` and
`onChange`. Set `name` and it submits inside a plain form.

<Notice tone="info">
Inside something that scrolls or clips, such as a Modal's body, set `portal` so the panel is not
cut off.
</Notice>

## Accessibility

- A name is required, as `label` or `aria-labelledby`.
- Focus stays on the trigger. The arrow keys move the highlight, Enter or Space chooses, and typing
  a letter jumps to the next option starting with it.
- Escape or a click outside closes it. The selected option carries a check, not only a colour.
