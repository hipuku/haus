## Usage

```tsx

<Textarea label="Notes" rows={4} value={notes} onChange={e => setNotes(e.target.value)} />
```

## States

`hint`, `error` and `required` work as on Input. `rows` sets the starting height, and the user can
make it taller. A disabled Textarea cannot be resized.

## Accessibility

- A native textarea with a real `label`. Enter adds a line, and Tab moves on.
- The hint and error are read as its description, and an error is announced when it appears.
- `required` and `error` set `aria-required` and `aria-invalid`.
