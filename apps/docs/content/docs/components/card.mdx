## Usage

```tsx
import { Card } from '@/components/haus/components/Card'

<Card>
  <h3>Usage this month</h3>
  <p>12,400 requests</p>
</Card>
```

## Variants

| `variant` | Use it for |
| --------- | ---------- |
| `default` | A bordered surface. The one to reach for |
| `elevated` | A card that floats or overlaps the page |
| `outlined` | A selected or highlighted card |

Turn `padding` off for content that runs to the edge, such as an image at the top.

## Choosing the element

Use `as` for the right element: `li` in a list of cards, `article` or `aside` where they belong.
For a card that is a link, pass the link as the single child with `asChild`:

```tsx
<Card asChild>
  <Link href="/projects/haus">haus</Link>
</Card>
```

## Accessibility

- A plain card takes no focus. Controls inside it keep their own.
- A card made a link or button with `asChild` becomes the control, with a visible focus outline.
- Render a list of cards with `as="li"` inside a list, so it is announced as a list.
