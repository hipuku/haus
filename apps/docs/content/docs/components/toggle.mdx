## Usage

```tsx

<Toggle
  label="Weekly digest"
  description="A summary every Monday"
  checked={digest}
  onChange={setDigest}
/>
```

## Sizes and layout

`sm` and `md`, with `md` the default. The label sits before the switch; `labelPosition="right"`
puts it after. `onChange` gives you `(checked, event)`.

<Notice tone="info">
A Toggle has no `error`, because a switch applies at once and there is nothing to submit later. For
a choice that is saved with a form, use Checkbox.
</Notice>

## Accessibility

- Announced as a switch, on or off, and Space flips it.
- The label is its name and the description is read as its description.
- Inside a form with a `name`, it posts a value only while it is on.
