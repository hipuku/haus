## Tones

`neutral`, `info`, `success`, `warning` and `error` carry meaning. `primary` is the brand colour
and carries none. Each tone is `subtle` or `solid` through `appearance`.

## Choosing the element

`as` sets the element when a `span` is wrong: a count in a definition list is a `dd`, and a value
that updates is an `output`, which a screen reader announces when it changes.

## Accessibility

- Read as its text and takes no focus.
- The word carries the meaning, never the colour alone: write a label that stands on its own.
