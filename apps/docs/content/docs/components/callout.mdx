## Tones

`neutral`, `info`, `success`, `warning` and `error`, each with its own glyph. Replace the glyph
with `icon`, or remove it with `icon={false}`.

## Announcing it

`live` decides whether a screen reader announces the callout. Pick by how it got there:

| `live` | Use it when |
| ------ | ----------- |
| `off` | It was on the page from the start, such as a caveat or guidance. The default |
| `polite` | It appeared in response to something, such as save or validation feedback |
| `assertive` | It appeared and the reader must hear it now. Interrupts whatever is being read |

<Notice tone="info">
A Callout stays in the page beside what it describes. For a passing message about an event, use
Toast.
</Notice>

## Accessibility

- Not interactive. Links inside it keep their place in the tab order.
- The glyph is decorative: the text must carry the meaning without the colour.
