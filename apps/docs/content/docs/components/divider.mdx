## Spacing

`spacing` sets the room on either side: `sm`, `md` or `lg`, or `none`. A vertical divider takes it
on either side horizontally, and stretches to the height of the row it sits in.

## Decorative or not

By default a Divider is announced as a separator between two groups. Set `decorative` when the
line is only visual, such as one drawn to break up a dense panel, and it is hidden from screen
readers.

## Accessibility

- Always an `<hr>`, so it is a break even with styles off.
- Not interactive.
