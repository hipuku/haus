## Usage

```tsx
import { Tabs } from '@/components/haus/components/Tabs'

<Tabs
  aria-label="Project"
  items={[
    { label: 'Overview', value: 'overview' },
    { label: 'Activity', value: 'activity' },
  ]}
  value={tab}
  onValueChange={setTab}
>
  {tab === 'overview' ? <Overview /> : <Activity />}
</Tabs>
```

## Appearances

`underline` is the default, for sections. `segmented` fills the selected tab inside a track, for a
two or three way mode switch.

## Rendering the panel yourself

Tabs renders the panel from `children`. When the panel has to sit elsewhere on the page, pass
`panelId` and an `id` instead, and give your panel `role="tabpanel"`, `tabIndex={0}` and
`aria-labelledby={tabIdFor(id, value)}`, using the exported `tabIdFor`.

## Accessibility

- A name is required, as `aria-label` or `aria-labelledby`.
- The tablist is one tab stop. The arrow keys move between tabs and wrap, Home and End jump, and
  disabled tabs are skipped. Selection follows focus.
- Tab from the tablist moves into the panel.
