## Writing it

An empty state is mostly a sentence, and there are three different ones:

| Situation | Say | Action |
| --------- | --- | ------ |
| Nothing yet | There is nothing here, and how to start | The control that starts it |
| Filtered to nothing | The filter is too narrow | Clear the filter |
| Could not load | It failed, which is not the same as empty | Retry, or none |

Leave out `action` when nothing the reader can do would fill the space.

<Notice tone="warning">
Set `live="polite"` when the empty state appears in response to something, such as a search with
no results or a failed load. Otherwise it is not announced, and a failure reads as an empty list.
</Notice>

## Accessibility

- `title` is a real heading. Set `headingLevel` to fit the page: it defaults to `3`.
- The icon is decorative. The title carries the meaning.
- The action keeps its own place in the tab order.
