## Usage

```tsx
import { Popover } from '@/components/haus/components/Popover'

const trigger = useRef<HTMLButtonElement>(null)

<div style={{ position: 'relative' }}>
  <Button ref={trigger} aria-expanded={open} onClick={() => setOpen(o => !o)}>
    Share
  </Button>
  <Popover open={open} onClose={() => setOpen(false)} triggerRef={trigger} aria-label="Share">
    {shareForm}
  </Popover>
</div>
```

<Notice tone="warning">
The element wrapping the trigger and the Popover needs `position: relative`. The panel is placed
against it.
</Notice>

## Placement and width

- `placement` puts the panel `bottom` or `top` of the trigger.
- `align` lines it up with the trigger's `start` or `end` edge, or `stretch`es it across.
- `width` is `auto` to fit its content, `trigger` to be at least as wide as the trigger, or a fixed
  step for a panel holding a form. A panel grows to fit long content either way.

## Inside something that scrolls

Set `portal` when the trigger is inside something that clips or scrolls. The panel is then placed
over the page from the trigger's position, so it is not cut off.

## Accessibility

- `triggerRef` is required: Escape closes the panel and returns focus to the trigger.
- A name is required, as `aria-label` or `aria-labelledby`. `role` is `dialog`, `menu`, `listbox`
  or `group`, and only `menu` promises arrow-key navigation: use Menu for that.
- Not a focus trap. Tabbing out of the panel closes it, and a click outside closes it.
