## Usage

```tsx
import { Modal } from '@/components/haus/components/Modal'

<Modal
  open={open}
  onClose={() => setOpen(false)}
  title="Invite people"
  initialFocus={emailRef}
  footer={<Button variant="primary" onClick={invite}>Send invites</Button>}
>
  <Input ref={emailRef} label="Email" />
</Modal>
```

## API

Modal also takes its element's own attributes and forwards its ref. `className` lands on the
backdrop and `dialogClassName` on the dialog.

## Size and placement

`size` sets the dialog's width. `placement` is `center` by default; `start` and `end` anchor it to
an edge at full height, which is what Drawer does for you.

## Dismissing

Escape, the close button and a click on the backdrop all call `onClose`. Turn
`dismissOnBackdrop` off for anything destructive or anything holding unsaved input, so a stray
click does not lose work.

<Notice tone="info">
A Select or Popover inside a Modal is placed inside the dialog automatically, so it stays inside
the focus trap and is not clipped by the dialog's scrolling body.
</Notice>

## Accessibility

- A name is required: `title`, or `aria-label` when there is no visible title.
- Focus moves into the dialog on open, to `initialFocus` if you set it, and returns to what had it
  on close.
- Tab stays inside the dialog, and the page behind does not scroll.
