Two questions about a pair. **Distance** is whether a person can tell them apart, measured as
CIEDE2000, where about 1 is the smallest visible difference. **Contrast** is whether one can carry
text on the other, measured by WCAG 2. A pair can be easy to tell apart and still fail as text.

contrast tests use. Nothing is uploaded.
