Design tools disagree about how a token is written down, and moving between them quietly drops
things. This converter reads DTCG, Figma variables, Tokens Studio and Tailwind v4, writes any of
them, and shows you what did not survive.

<ConverterWorkspace />

## Reading the result

- **Files** is what was written, one tab per file, with copy and download.
- **Tokens** is the model the engine read: every token, its type, and its value in each mode, with
  references shown as `{path}`. This is the one model all four formats pass through.
- **Report** is what did not survive. **Lost** is what the target cannot hold, such as a second mode
  in a format with one value per token. **Translated** changed how a value is written and kept what
  it means, such as a unit converted or an alias resolved.

## It runs here

This is [`@hipuku/dtcg`](/docs/packages/dtcg) itself, the same build a consumer installs, compiled
to run in the page. Nothing is uploaded, nothing is stored, and the conversion you see is the
conversion the command line would give you.
