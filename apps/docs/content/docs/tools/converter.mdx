Design tools disagree about how a token is written down, and moving between them quietly drops
things. This converter reads DTCG, Figma variables, Tokens Studio and Tailwind v4, writes any of
them, and shows you what did not survive.

<ConverterWorkspace />

## Lost and translated

The report separates two things a conversion does, and the difference is the whole point of
reading it.

**Lost** is what the target cannot hold. A second mode in a format with one value per token, a
composite with no equivalent, a description with nowhere to go. It is not in the output.

**Translated** changed how a value is written and kept what it means. A unit converted, an alias
resolved to the value it pointed at, a colour written in another space. It is in the output, as
something else.

A conversion with nothing lost is reversible. One with a long translated list is fine to ship and
awkward to bring back.

## It runs here

This is [`@hipuku/dtcg`](/docs/packages/dtcg) itself, the same build a consumer installs, compiled
to run in the page. Nothing is uploaded, nothing is stored, and the conversion you see is the
conversion the command line would give you.
