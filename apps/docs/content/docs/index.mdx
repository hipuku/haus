haus ships components as source through a [shadcn](https://ui.shadcn.com) registry, and its design
tokens as a package on npm (`haus-tokens` today, `@hipuku/tokens` from the next release). A
component you install is a copy in your own repository: restyle it freely, and take behaviour fixes
from haus with `shadcn add`.

<GetStarted />

## What you install

A copy of the component in your own repository, not a dependency you cannot reach into. Every one
of these is the published component, rendered on this page: tab through them, or switch the mode in
the header and watch them follow.
