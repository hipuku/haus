haus is the design system every hipuku app is built on. It is two things a consumer takes
separately: components distributed as source through a [shadcn](https://ui.shadcn.com) registry,
and the design tokens underneath them, published on npm (`haus-tokens` today, `@hipuku/tokens`
from the next release).

<GetStarted />

## What arriving as source means

A component you install is a copy in your own repository. There is no package boundary between you
and it: open the file, read it, restyle it, delete the half you do not need. When a behaviour fix
lands here, `shadcn add` brings the new copy and you merge it like any other change to your own
code.

The trade is deliberate. A dependency can be upgraded in one line and cannot be reached into; a
copy can be reached into and has to be upgraded on purpose. For an interface, which is the part of
an app most often wrong in ways only its own team can see, being able to reach in is worth more
than the upgrade being free.

The tokens go the other way. They are a package, versioned and installed, because a value is not
something a product should fork: two apps whose `surface-raised` has drifted apart are two apps
that no longer look like one company.

## Three decisions

Nearly everything on this site is a consequence of three choices, and each has a page that shows
the evidence rather than restating the claim.

**A component never names a value.** It names a role: the surface it sits on, the ink it writes
in, the border that is its edge. One component is then correct in a light app, a dark one, and in
another brand, without a line of it changing. See [Colour](/docs/foundations/colour).

**A dark mode is the same mapping read again.** Every role carries a value per mode, resolved from
the theme on the document or the reader's system setting, so there is one mapping rather than a
light set and a dark set that can drift apart. See [Theming](/docs/foundations/theming).

**Contrast is a test, not an intention.** `contrast.test.ts` in the token package holds every ink
and surface pair against WCAG AA in both modes, so a pair that would fail does not get released.
See [Quality](/docs/start/quality).
