haus ships components as source through a [shadcn](https://ui.shadcn.com) registry, and its design
tokens as a package on npm (`haus-tokens` today, `@hipuku/tokens` from the next release). A component you install is a copy in your own
repository: restyle it freely, and take behaviour fixes from haus with `shadcn add`.

New here? [What haus is](/docs/start) explains the four layers and what has already been decided,
and [Install](/docs/start/install) is the two lines that set it up.
