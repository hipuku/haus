A design decision should be written down once. `@hipuku/tokens` holds all of them, in three forms
built from the same source: custom properties for stylesheets, typed constants for the places CSS
cannot reach, and DTCG JSON for design tools. A value cannot differ between them, because none of
them is written by hand.

## What is in it

Four layers, each importable on its own, and each depending only on the one above it.

| Layer | Holds | Example |
| ----- | ----- | ------- |
| Primitives | The raw scales, with no meaning attached | `--haus-text-16`, `--haus-color-damson-50` |
| Semantics | Roles, which are what a component reads | `--haus-color-surface-raised`, `--haus-type-body-size` |
| Brand | Which primitive each role takes, per product | `--haus-brand-radius-surface` |
| Motion | Durations, easings and the three modes | `--haus-motion-press-duration` |

A component never names a primitive. It names a role, and a brand file decides what that role
resolves to, which is what lets one component be correct in hipuku's colours, vault's and core's
without a line of it changing. The [foundations](/docs/foundations/colour) pages show each layer
with its live values.

## Install

```bash
npm install @hipuku/tokens
```

Import the barrel once, at the root of your app. It loads every layer in the order they depend on
each other, which a hand-written set of imports gets wrong eventually.

```ts
import '@hipuku/tokens/index.css'
```

## The three forms

| Form | Import | For |
| ---- | ------ | --- |
| Custom properties | `@hipuku/tokens/index.css`, or one layer such as `@hipuku/tokens/motion.css` | Stylesheets |
| Typed constants | `import { tokens } from '@hipuku/tokens'` | Build config, media queries, canvas |
| DTCG JSON | `@hipuku/tokens/tokens.json` | Figma, Tokens Studio, other token tooling |
| Brand files | `@hipuku/tokens/brands/core.css`, `/brands/vault.css` | A product's own colours and radii |

Every custom property starts with `--haus-`. Mode is an attribute, not a build: `data-theme` picks
light or dark, `data-haus-theme` picks the brand, and `data-haus-motion` picks the motion mode
(`expressive` or `reduced`, with reduced also applying under `prefers-reduced-motion`).

## The guard

Tokens only hold if nothing goes around them. `@hipuku/tokens/guard` reads a consumer's stylesheets
and reports any colour, length or duration written as a literal where a token exists, so the rule is
a build step rather than a review comment.
