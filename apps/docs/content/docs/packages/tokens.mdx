## Install

```bash
npm install haus-tokens
```

## Usage

Import the stylesheets once, at the root of your app. The barrel loads every layer in the right
order:

```ts
import 'haus-tokens/index.css'
```

| Form | Import | For |
| ---- | ------ | --- |
| CSS custom properties | `haus-tokens/index.css`, or a single layer such as `haus-tokens/motion.css` | Styling |
| Typed constants | `import { tokens } from 'haus-tokens'` | Build config and media queries |
| DTCG JSON | `haus-tokens/tokens.json` | Design tools and other token tooling |
| Brand files | `haus-tokens/brands/core.css`, `haus-tokens/brands/vault.css` | A product's own brand |

Every custom property starts with `--haus-`. The motion roles switch mode with a `data-haus-motion`
attribute (`expressive` or `reduced`); reduced also applies under `prefers-reduced-motion`.
