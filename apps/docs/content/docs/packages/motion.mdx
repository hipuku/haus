The numbers behind haus's motion roles: duration caps, springs compiled to CSS, sheet drag physics
and presence state. Plain functions, so the same values serve CSS, tests and canvas.

<PackageMeta dir="motion" />

## Install

```bash
npm install @hipuku/motion
```

## Usage

```ts
import { capDuration, springToLinear } from '@hipuku/motion'

springToLinear({ visualDuration: 0.2, bounce: 0 })
// { durationMs: 353, easing: 'linear(0, 0.0229, 0.0789, …, 1)' }

capDuration('highlight', 500) // 300: the highlight role's cap
```

A spring is described by how long it looks like it moves (`visualDuration`) and how far it
overshoots (`bounce`). `durationMs` is how long CSS has to run for it to settle, which is longer than
it looks. These are the same values the `--haus-motion-*` custom properties carry.

## What it covers

| Piece | For |
| ----- | --- |
| `capDuration` | Holds a duration to its role's cap |
| `springToLinear` and friends | A spring as a CSS `linear()` easing, with its settle time |
| `VelocityTracker`, `releaseTarget`, `rubberBand` | Dragging a sheet or drawer, and where it lands |
| `presence`, `isMounted` | Keeping an element mounted while it animates out |
