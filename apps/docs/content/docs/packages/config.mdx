Eleven repositories, one house style. `@hipuku/config` holds the TypeScript bases, the Prettier
preset and the two prose checks in one package, so a decision about how code is written is made
once and reaches every repository through a version bump rather than through eleven pull requests.

<PackageMeta dir="config" />

## Install

```bash
npm install --save-dev @hipuku/config
```

## Usage

A TypeScript base, extended from `tsconfig.json` (`base`, `react` or `node`):

```json
{ "extends": "@hipuku/config/tsconfig/react.json" }
```

A Prettier preset, named in `package.json` (`prettier`, or `prettier/wide` for 120 columns, no
semicolons and single quotes):

```json
{ "prettier": "@hipuku/config/prettier/wide" }
```

The two checks, as scripts:

```json
{
  "scripts": {
    "lint:prose": "hipuku-check-prose",
    "lint:names": "hipuku-check-names"
  }
}
```

`hipuku-check-prose` holds each file to a per-file baseline, so the count can come down and never
go up; `hipuku-check-names` fails on a blocked name in a file or a commit message.

## API

There is none. The package is configuration and two commands.

The full reference is the [package README](https://github.com/hipuku/haus/tree/main/packages/config).
