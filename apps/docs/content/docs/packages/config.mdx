`@hipuku/config`, unreleased at 0.1.0. One place to change, so a fix reaches every repository
through a version bump.

## Install

Not on npm yet.

```bash
npm install --save-dev @hipuku/config
```

## Usage

A TypeScript base, extended from `tsconfig.json` (`base`, `react` or `node`):

```json
{ "extends": "@hipuku/config/tsconfig/react.json" }
```

A Prettier preset, named in `package.json` (`prettier`, or `prettier/wide` for 120 columns, no
semicolons and single quotes):

```json
{ "prettier": "@hipuku/config/prettier/wide" }
```

The two checks, as scripts:

```json
{
  "scripts": {
    "lint:prose": "hipuku-check-prose",
    "lint:names": "hipuku-check-names"
  }
}
```

`hipuku-check-prose` fails on an em dash against a per-file baseline; `hipuku-check-names` fails on a
blocked name in files and commit messages. The package has no JavaScript API. The full reference is the
[package README](https://github.com/hipuku/haus/tree/main/packages/config).
