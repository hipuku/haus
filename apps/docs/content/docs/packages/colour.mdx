Contrast in haus is a test rather than a hope, and something has to do the arithmetic.
`@hipuku/colour` is that something: perceptual distance, WCAG contrast, conversion between spaces,
and a matcher that gives a colour its nearest human name. The contrast suite in CI runs these
functions, and so do the swatches on the [colour foundation](/docs/foundations/colour), which is why
the numbers on that page are measured rather than written down.

<PackageMeta dir="colour" />

## Install

Not on npm yet. It replaces `haus-colour-utils` and `haus-colour-names`, which are, and which it is
not a drop-in for: the names moved to a subpath and the function names changed.

```bash
npm install @hipuku/colour
```

## Usage

```ts
import { deltaE, wcagContrast, createNamedColourMatcher } from '@hipuku/colour'
import { colourNameEntries } from '@hipuku/colour/names'

deltaE('#4f84ba', '#4e83bd') // 0.66, below the threshold a person can see
wcagContrast('#000', '#fff').ratio // 21

const nameColour = createNamedColourMatcher(colourNameEntries())
nameColour('#4f84ba')[0] // { name: 'Blue Vault', hex: '#4e83bd', distance: 0.7 }
```

`deltaE` is CIEDE2000, so a difference of 1 is roughly the smallest a person can see, and two
colours can be compared across hues without one of them winning for being brighter.

## The names are a separate import

The 31,900 colour names are 764KB, which is not something to post to everyone who wants a contrast
ratio. They live on their own subpath, so a bundler leaves them out unless `@hipuku/colour/names` is
imported.

It exports `colourNames`, `colourNameEntries` and `COLOUR_NAME_COUNT`.
