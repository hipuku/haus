The arithmetic behind haus's contrast checks and the measured values on the colour foundation page.

<PackageMeta dir="colour" />

## Install

```bash
npm install @hipuku/colour
```

<Notice tone="info">
It replaces `haus-colour-utils` and `haus-colour-names`, which are deprecated. It is not a drop-in:
the function names changed and the names moved to a subpath.
</Notice>

## Usage

```ts
import { deltaE, wcagContrast, createNamedColourMatcher } from '@hipuku/colour'
import { colourNameEntries } from '@hipuku/colour/names'

deltaE('#4f84ba', '#4e83bd') // 0.66: below what a person can see
wcagContrast('#000', '#fff').ratio // 21

const nameColour = createNamedColourMatcher(colourNameEntries())
nameColour('#4f84ba')[0] // { name: 'Blue Vault', hex: '#4e83bd', distance: 0.7 }
```

`deltaE` is CIEDE2000: a difference of about 1 is the smallest a person can see.

## The names subpath

The 31,900 colour names are close to 1MB, so they are a separate import, `@hipuku/colour/names`, and
a bundler leaves them out unless you import it. It exports `colourNames`, `colourNameEntries` and
`COLOUR_NAME_COUNT`.
