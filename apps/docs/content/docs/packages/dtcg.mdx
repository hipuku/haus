Four tools in a design pipeline, four token formats, and no two of them agree. `@hipuku/dtcg` reads
all four into one model, writes that model back out as any of them, and tells you exactly what each
conversion could not carry, per token, with the reason.

That last part is the point. Every converter loses something: Tailwind has no concept of a mode on a
single token, Figma variables cannot hold a typography composite. A converter that loses it silently
is worse than one that refuses, so this one hands back a loss report and lets the caller decide.

The [converter tool](/docs/tools/converter) on this site is this package running in your browser.

## The four formats

| Format | Read | Written | Notes |
| ------ | ---- | ------- | ----- |
| DTCG | Yes | Yes | Resolver documents with modes included |
| Figma variables | Yes | Yes | The export shape, collections and modes |
| Tokens Studio | Yes | Yes | Sets and themes |
| Tailwind v4 | Yes | Yes | `@theme` stylesheets |

## Install

```bash
npm install @hipuku/dtcg
```

## Usage

```ts
import { readFileSync } from 'node:fs'
import { convert } from '@hipuku/dtcg'

const text = readFileSync('tokens.json', 'utf8')
const result = convert([{ name: 'tokens.json', text }], 'tailwind')
result.format // the format detected in the input
result.files // the written output, one or more files
result.allLosses // what was lost reading, then writing, each with the token, reason and detail
```

`read` and `write` are the two halves of `convert`. `detectFormat` names the format of a set of
documents from their shape.

## The dtcg command

The package installs a `dtcg` command. Run it from a project that has `@hipuku/dtcg`
installed: without a local install, `npx dtcg` fetches the unrelated `dtcg` package from npm.

```bash
npx dtcg tokens.json --to tailwind > theme.css
npx dtcg theme.css --from tailwind --to figma --out figma/
```

With `--out`, every output file is written into that directory. Without it, a single output file
goes to stdout, and more than one is an error. The loss report goes to stderr, one line per loss.

| Option | Meaning |
| ------ | ------- |
| `--to <format>` | `dtcg`, `figma`, `tokens-studio` or `tailwind`. Required |
| `--from <format>` | The input format. Detected when left out |
| `--out <dir>` | Write the output files here |
| `--rem-base <px>` | Pixels per rem. Default 16 |
| `--mode-selector <kind>` | How a Tailwind stylesheet switches modes: `data-theme`, `class` or `media` |

Exit codes: 0 converted, 1 the input could not be read or names an output file outside `--out`, 2
the command was wrong, 3 the output could not be written.
