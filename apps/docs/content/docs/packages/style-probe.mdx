Reads an element's computed style from a live page and returns typed values, so a test can assert
what a component really draws. It is how haus's Figma parity check measures components.

<PackageMeta dir="style-probe" />

## Install

```bash
npm install @hipuku/style-probe
```

## Usage

Two halves: `extractRawElements` runs in the page, and `normaliseElement` turns its strings into
comparable values anywhere. With Playwright:

```ts
import { extractRawElements, normaliseElement } from '@hipuku/style-probe'

const raw = await page.evaluate(extractRawElements, { root: '#probe' })
const [button] = raw.map(normaliseElement)

button.styles.backgroundColor // '#2563eb'
button.styles.padding // [8, 16, 8, 16]
```

`root` reads one element and its subtree. Leave it out to read the whole page.
